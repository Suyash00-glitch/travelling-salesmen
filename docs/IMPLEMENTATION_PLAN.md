# LoomOS implementation plan

1. Establish normalized PostgreSQL records, migrations, role contracts and demonstrably transactional services.
2. Implement identity, sales, yarn receipt/reservation, sequential job cards and material consumption.
3. Connect machines, roll provenance, inspection history, rework and atomic dispatch/invoices.
4. Connect attendance, wages, payment records and explainable costs to operational reporting.
5. Build the premium responsive workspace, feature forms, roll passport and scoped buyer portal against real APIs.
6. Seed a coherent demonstration factory; verify concurrency, permissions, accounting and the complete workflow. Check the interface in a browser.

Design: warm canvas, ink typography, forest-green navigation, restrained lime highlights, thin borders, tabular numbers, generous whitespace and purposeful motion. All operational values originate in the API.

The existing frontend/backend README files are preserved. Executable work uses the requested apps/web, apps/api, packages/db and packages/shared workspace.
